## Week 2 — Data Visualization and Insight Communication using R

**Objective:** Create dynamic, informative visualizations in R to communicate key insights to both technical and non-technical audiences.

**Dataset:** Titanic passenger dataset (continued from Week 1, cleaned — 891 records, 19 variables).

**Key highlights:**
- 10 visualizations across three R plotting systems: ggplot2, base R graphics, and lattice
- Chart types: grouped/stacked bar charts, histogram with density overlay, faceted scatter plots, line chart, boxplot, pie chart, and dot plot
- Each chart paired with its rationale, R code, and a plain-language insight
- Closing synthesis section ties all findings into a single narrative on survival drivers

**Files in this folder:**
- `Week2_Data_Visualization_R_Report.docx` — full report with narrative, code, and visuals
- `visualize.R` — complete reproducible R script
